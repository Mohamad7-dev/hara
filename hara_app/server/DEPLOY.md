# حارة — الربط ببوابة الدفع والنشر

## الواقع الحالي
- تطبيق حارة يعمل الآن بدفع **الكاش عند الاستلام** (يُحصَّل من الموصّل بزّر «تحصيل المبلغ») + **دفع إلكتروني بوضع المحاكاة**.
- البوابات المعروفة لا تغطي فلسطين: myFatoorah (خليج/مصر/الأردن) وeFAWATEERcom (أردني). **لا تربطهما بفلسطين.**

## البوابة الفلسطينية الصحيحة
- **PalPay (محفظتي)** — رام الله، مشروع مشترك بين **بنك فلسطين** وPCNC، مرخّص من سلطة النقد الفلسطينية.
  - خدمة التجار: `https://www.palpay.ps/en/merchants/e-commerce-service`
  - هاتف: +970 1700 102 010 — البريد: info@palpay.ps
- **Jawwal Pay** — محفظة فلسطينية (الشركة الوطنية للدفع الإلكتروني / مجموعة الاتصالات الفلسطينية).
- أو **حساب تاجر بطاقات فيزا/ماستركارد** عبر بنك فلسطين/بنكك.

## خطوات التفعيل (خطوة واحدة إلزامية منك)
1. وقّع اتفاقية تاجر مع PalPay (أو Jawwal Pay / بنكك).
2. اطلب مستندات **API الدفع الإلكتروني** + المفاتيح (تاجر، اسم مستخدم، كلمة مرور، توقيع، وربط webhook).
3. عبّئ القيم في `server/.env` (انظر `.env.example`).
4. أرسل لي المستندات — أُضيف نداءاتهم داخل `_palpay_intent` في `server/main.py` (المكان جاهز ومحجوز).

## النشر السحابي (مطلوب لوصول webhook إليك)
السيرفر يحتاج عنواناً عاماً HTTPS حتى ترسل إليه البوابة تأكيد الدفع (webhook). خطوات Render:

1. ارفع مجلد `server/` إلى مستودع Git.
2. في Render: **New → Web Service** → اربط المستودع.
3. الإعدادات:
   - Build: `pip install -r requirements.txt`
   - Start: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - Variables: انسخ `server/.env` إلى متغيرات البيئة في Render.
4. بعد النشر، انسخ رابط webhook: `https://<app>.onrender.com/api/payments/webhook` وضعْه في لوحة بوابة الدفع (وعيّن `MYFATOORAH_CALLBACK`/`PALPAY_CALLBACK` حسب البوابة).

## اختبار الجاهزية
```bash
curl https://<app>.onrender.com/api/config
# يجب أن يعود: {"onlinePayment": true, "gateway": "palpay"}
```

## سير اختبار محلي (بدون بوابة)
- أي طلب بدفع إلكتروني يعمل بوضع المحاكاة: `POST /api/payments/simulate/{orderId}` يجعله مدفوعاً.
- كل التدفقات الأخرى (كاش، إشعارات، موصّل) تعمل فعلياً.
